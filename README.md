# RSSI_WIFI

**Система бесконтактной оценки пульса по изменениям уровня Wi-Fi RSSI с использованием ESP8266 и методов цифровой обработки сигналов.**

Проект предназначен для экспериментального исследования возможности извлечения физиологически обусловленных периодических компонентов из изменений уровня принимаемого Wi-Fi-сигнала (RSSI, Received Signal Strength Indicator).

ESP8266 используется в качестве измерительного узла: устройство подключается к беспроводной сети, измеряет RSSI и передаёт последовательность значений на сервер через WebSocket. Серверная часть обеспечивает сбор экспериментальных данных, их сохранение в CSV и обработку сигнала в режиме реального времени.

## Основные возможности

- измерение Wi-Fi RSSI с помощью ESP8266;
- частота регистрации данных около 20 Гц;
- передача измерений через WebSocket;
- сохранение исходных RSSI-данных в CSV;
- обработка сигнала в режиме реального времени;
- удаление постоянной составляющей и тренда;
- полосовая фильтрация;
- декомпозиция сигнала методом EEMD;
- выделение информативной компоненты с помощью PCA;
- спектральный анализ методом FFT;
- оценка частоты периодической компоненты и её преобразование в BPM;
- медианная стабилизация последовательности оценок.

## Аппаратная часть

Прошивка рассчитана на платформу **ESP8266** и собирается с использованием PlatformIO и Arduino Framework.

Конфигурация проекта:

```ini
[env:esp12e]
platform = espressif8266
board = esp12e
framework = arduino
monitor_speed = 115200
```

ESP8266 периодически получает значение RSSI текущего Wi-Fi-соединения и передаёт пару

```text
timestamp,rssi
```

на WebSocket-сервер.

## Частота измерений

В текущей конфигурации интервал между измерениями составляет:

```text
50 ms
```

что соответствует приблизительно:

```text
20 Hz
```

## Обработка RSSI

Для оценки периодической составляющей используется последовательный пайплайн обработки.

### 1. Удаление постоянной составляющей

Из последовательности RSSI вычитается среднее значение.

### 2. Полосовая фильтрация

Применяется полосовой фильтр Баттерворта.

Текущий диапазон:

```text
0.5–3.5 Hz
```

### 3. EEMD

Для декомпозиции нестационарного RSSI-сигнала используется **Ensemble Empirical Mode Decomposition (EEMD)**.

Полученные intrinsic mode functions используются для дальнейшего выделения информативной компоненты.

### 4. PCA

Выбранные IMF-компоненты объединяются с помощью **Principal Component Analysis (PCA)**.

Первая главная компонента используется как результирующий сигнал для спектрального анализа.

### 5. FFT

Для определения доминирующей периодической компоненты выполняется быстрое преобразование Фурье.

В текущей реализации анализируется частотный диапазон:

```text
1.0–2.0 Hz
```

Полученная частота преобразуется в количество циклов в минуту:

```text
BPM = frequency × 60
```

Для уточнения положения спектрального максимума используется параболическая интерполяция.

### 6. Стабилизация

Последовательность оценок BPM дополнительно сглаживается медианным фильтром.

## Структура репозитория

```text
RSSI_WIFI/
├── src/
│   └── main.cpp
├── data_collector.py
├── server_ws.py
├── plot_full_analysis.py
├── platformio.ini
└── .gitignore
```

### `src/main.cpp`

Прошивка ESP8266:

- подключение к Wi-Fi;
- подключение к WebSocket-серверу;
- измерение RSSI;
- передача данных с частотой около 20 Гц;
- автоматическое восстановление WebSocket-соединения.

### `data_collector.py`

Сервер сбора и обработки данных.

Поддерживаются два режима:

```text
realtime
collect
```

`realtime` выполняет обработку RSSI и оценку BPM.

`collect` сохраняет входящие измерения в CSV без обработки.

### `plot_full_analysis.py`

Инструменты анализа и визуализации экспериментальных данных.

### `server_ws.py`

WebSocket-сервер для работы с поступающим потоком RSSI.

## Установка Python-зависимостей

Для обработки сигнала необходимы Python и соответствующие научные библиотеки.

```bash
pip install numpy scipy scikit-learn EMD-signal websockets
```

## Сбор экспериментальных данных

Запустите сервер в режиме записи:

```bash
python data_collector.py --mode collect
```

По умолчанию будет создан файл вида:

```text
rssi_YYYYMMDD_HHMMSS.csv
```

Можно явно указать имя файла:

```bash
python data_collector.py --mode collect --output experiment.csv
```

CSV имеет структуру:

```text
timestamp,rssi
```

## Работа в реальном времени

Запуск обработки:

```bash
python data_collector.py --mode realtime
```

После накопления необходимого объёма данных сервер выполняет обработку RSSI-сигнала и выводит оценку BPM.

## Прошивка ESP8266

Проект использует PlatformIO.

Перед запуском необходимо настроить параметры Wi-Fi и адрес WebSocket-сервера в:

```text
src/main.cpp
```

После настройки прошивку можно собрать и загрузить на ESP8266 средствами PlatformIO.

## Ограничения

Проект является исследовательским прототипом.

Оценка пульса основана на анализе изменений RSSI и чувствительна к:

- расположению передатчика и приёмника;
- движению человека;
- многолучевому распространению;
- изменениям окружающей среды;
- помехам Wi-Fi;
- параметрам фильтрации и временного окна.

Получаемые значения не следует рассматривать как медицинские измерения или использовать для клинической диагностики.

## Воспроизводимость

Для воспроизводимых экспериментов рекомендуется сохранять исходные RSSI-последовательности в режиме `collect` и выполнять последующий анализ на неизменённых наборах данных.

При публикации результатов следует фиксировать:

- используемое оборудование;
- положение ESP8266 и точки доступа;
- частоту дискретизации;
- продолжительность записи;
- параметры фильтрации;
- параметры EEMD;
- параметры PCA;
- диапазон FFT-анализа.
